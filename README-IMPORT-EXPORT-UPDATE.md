# Updating the RPG Maker Management Scripts

If rmxp-plugin-system is empty, you need to run this command in git bash!:

`git submodule update --init --recursive`

Updating to the newest Ruby may also be required. It's avaliable at <https://rubyinstaller.org/downloads/> as always.

When cloning the project onto a new computer, add `--recurse-submodules` to the command to skip having to run the above command separately.
